# Laravel Livewire Starter Kit — LTR

A customized and reusable Laravel Livewire Starter Kit designed as a solid starting point for building modern Laravel applications.

This template includes a clean LTR interface, authentication, reusable UI components, and a developer-focused project structure — customized for a fast and consistent development workflow.

✨ Features

* ⚡ Laravel
* 🔥 Livewire
* 🎨 Tailwind CSS
* 🧩 Flux UI
* 🔐 Authentication & user management
* 🌓 Dark mode
* 📱 Responsive layout
* 🧱 Reusable Blade & Livewire components
* 🧭 LTR layout
* 🛠️ Developer-friendly structure
* 🚀 Ready to customize and extend

### 📦 Tech Stack

Technology	Purpose
Laravel	Backend framework
Livewire	Dynamic UI & application logic
Blade	Server-side rendering
Tailwind CSS	Styling
Flux UI	UI components
Vite	Frontend asset bundling
MySQL / MariaDB	Database

### 🛠️ Development

For the usual Laravel development workflow:

php artisan serve
npm run dev

Useful commands:

php artisan migrate
php artisan optimize:clear
php artisan route:list

### 📌 Purpose

This project is primarily maintained as a personal reusable starter kit.

Its goal is to reduce repetitive setup work and provide a familiar foundation for future Laravel + Livewire projects.
